# Naming and project identity

`NUIF` is the current working name and repository slug, not yet a cleared standards trademark.

The [naming review](../../research/items/naming.md) recorded prior acronym use in an old Nexus User Input Framework and in a 2024 computer-vision paper, plus unrelated uses. This reconnaissance is not trademark clearance.

The architecture therefore separates human branding from protocol identity. Stable schema namespaces, extension IDs and version identifiers must not depend on a product trademark remaining unchanged.

Before v0.1 branding is promoted outside the research project:

1. perform repository/package/domain/trademark clearance in key jurisdictions;
2. decide whether `NUIF` is an acronym or a proper project name;
3. reserve crate/package/extension namespaces;
4. define conformance-mark governance separately from the open specification;
5. make any rename before third-party persisted documents become common.

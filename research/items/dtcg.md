# Summary
DTCG defines platform-agnostic token values, groups, aliases, types and extensions for interchange among design tools and translation systems.

## NUIF relevance
NUIF should reference or embed DTCG-compatible token semantics rather than invent an incompatible token vocabulary. NUIF adds document-level bindings from authored properties to token identities and resolved values.
